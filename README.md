# 山海兽弈 · SHAN HAI JUNGLE

Q 版山海经 3D 斗兽棋。7 列 × 9 行沙盘，赤霞山与苍岚泽对弈，三种模式，八只程序化生成的神兽。

## 启动

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

## 验收命令

```bash
npm test           # Vitest：规则引擎 + 确定性 AI
npm run build      # tsc --noEmit && vite build
npm run qa         # 构建后跑 Playwright 桌面/移动浏览器验收
```

`npm run qa` 会自动启动 Vite preview，跑完关闭。可用 `QA_URL` 指定已有服务，用 `QA_PORT` 换端口。

## 玩法

- **观战 · AI 对 AI**：双方自动落子，可暂停、继续、单步、回退，速度 0.5× / 1× / 2×。
- **人机对战**：可选执赤霞山或苍岚泽，三档棋力；撤回回到玩家上一次决策点。
- **本地双人**：同屏轮流落子，撤回只退一个半回合。

种子可用 `?seed=XXXX` 通过 URL 传入，例如 `http://127.0.0.1:5173/?seed=20261102`。

## 规则要点

等级自低而高：鼠 < 猫 < 狗 < 狼 < 豹 < 虎 < 狮 < 象。攻击方等级大于等于防守方即可吃子，同级互吃；陆地鼠可吃象，象不能吃鼠。

只有鼠能入水。鼠进出水域那一步不能吃子，水中鼠只能被水中鼠吃。狮虎可横竖跳过连续水域，落点是这条直线上的第一个陆地格，路径有鼠则不能跳。

敌兽进入对方陷阱后有效等级按 0 处理，离开立即恢复。任何棋子不能进入己方兽穴；进入对方兽穴立即获胜。

终局优先级：入穴 > 无合法着法 > 三次重复判和 > 连续 100 个无吃子半回合判和。

## 技术分层

```text
src/engine/    纯规则引擎与确定性 AI（不导入 React / Three.js）
src/scene/     Three.js 沙盘、程序化神兽、动画与镜头
src/components/ React 棋盘与无障碍键盘棋盘
src/App.tsx    三种模式的状态流与界面
scripts/qa.mjs Playwright 桌面/移动验收
```

AI 运行在 Web Worker 中，主线程只请求、播放动画、更新界面。Worker 不可用时回退到主线程同步计算，结果一致。

所有模型、纹理、图标与音效均在本地程序化生成，不加载远程图片、在线字体、外部 3D 模型或版权音频。

构建按 `react` 与 `three` 拆分 chunk，主包只保留应用代码。

## 规则面板

- 桌面端：右侧常驻侧栏，打开后仍能看到棋盘与行棋状态。
- 移动端：底部抽屉，从下沿弹出，不遮挡顶部状态栏。

## 音频

音效用 Web Audio API 实时合成，包含木石点击、落子、入水、跃河、吃子撞击、陷阱、鼓点、入穴与胜利钹声。首次用户交互后才创建音频上下文，静音与音量写入 `localStorage`。静音时不创建持续发声节点。

音效按「声」验收，需要真人听音确认。自动验收只检查音频上下文未抛错、静音开关状态持久化，不做音色与混响的主观判断。

## 复现说明

AI 的同分排序只由种子决定。相同种子、模式、难度与行棋方，整局走法一致。种子不改变规则。
